# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to every project space: the issue tracker, pull requests, discussions, and any other channel used for
project work.

In short: be respectful, assume good faith, keep criticism about the work, and do not harass or demean anyone.

## Reporting

Report conduct concerns to the maintainers through a
[private report on GitHub](https://github.com/panproto/panproto/security/advisories/new), marking the report as a
conduct matter. Reports are kept confidential. The maintainers will review each report and respond with the action
taken, following the enforcement guidelines of the Contributor Covenant.
